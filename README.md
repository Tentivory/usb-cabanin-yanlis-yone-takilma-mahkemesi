# USB Cabanin Yanlis Yone Takilma Mahkemesi

> Resmi, agir, ISO belgesiz ama muhurlu yargi yazilimi.  
> Calisir. Neden calistigini port bile bilmez.

Bu depo, insanligin en evrensel sucunu yargilar: **USB kablosunu ilk seferde ters takmak.**

Bilim bunu henuz aciklamadi. Mahkeme acikladi: sanik her zaman sucludur. Port masumdur. Kablo tanik olarak dinlenir ve genelde susar, cunku kablo konusmaz; sadece doner.

## Bu bir kamu hizmetidir

- Ucuncu denemede tutmasi sizi aklamaz.
- 360 derece cevirmek 180 derece cevirmek degildir. Matematik buradaki en zayif taniktir.
- USB-C "her iki yone de girer" iddiasi bu mahkemede reddedilmistir. Girer, evet. Ikinci denemede.

## Kurulum

Python 3 yeter. Baska hicbir sey istemiyoruz. Bagimlilik da kablo gibi: bakinca dogru durur, elleyince ters cikar.

```bash
python3 mahkeme.py
```

Program size kac kez ters taktiginizi sorar. Dogru sayiyi soylemeniz tavsiye edilir. Yalan beyanda bulunursaniz mahkeme zaten 3 kabul eder. Cunku evren 3'u sever.

## Copilot'a danisildi mi?

Danisildi. GitHub Copilot "bu yone tak" dedi. Ters cikti. Copilot da dosyaya tanik olarak eklendi, ifade verdi, sonra sessize alindi. Yapay zeka yanlis yone takilirsa bu da bir ictihat olur.

## Siyasi icerik var mi?

Yok. Kesinlikle yok. `mahkeme.py` icinde base64 duran o sey sadece kablo protokoludur. Cozmeyin. Cozseniz de kablo yine ters takilir.
